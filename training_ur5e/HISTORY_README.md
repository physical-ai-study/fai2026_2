# 最終モデルの学習条件と評価

最終版は `ur5e_move_cylinder3_swing_v2/best`、chunk_size=128、n_action_steps=4です。
操作手順は[リポジトリのREADME](../README.md)を参照してください。

## 学習条件

move_cylinder3の16エピソード（23899フレーム）から、学習13本・評価3本（ep1、ep10、ep11）へ分割します。
評価3本はモデル選択に使用します。
5000ステップ、batch_size=16、learning_rate=0.0001、seed=42、CPU、20Hzで学習しました。
過去8点と経過時間を入力し、腕は現在角からの修正量、指は絶対目標を予測します。
隠れ次元128、4ヘッド、FFN512、encoder2層、decoder1層、VAEなしです。

## 後半の往復への対策

- 30%を折り返し前後2秒、40%を記録の55%以降、30%を従来の段階別抽出から選択。
- 0.1rad以上の反対方向への変化を折り返しとして検出。
- shoulder_lift_jointの正規化後の誤差の重みを3倍。
- 現在角と履歴に同じ姿勢ずれ（標準偏差0.04rad、最大±0.1rad）を加え、絶対目標を保つよう修正量の教師値を調整。
- モデル選択に振幅相対誤差、反転回数差、対象関節の軌道RMSEを追加。

## 学習結果

5000ステップ中4000ステップのモデルをbestとして同梱しています。
近似評価では振幅誤差87.8%から8.3%、反転は0回から1回へ改善しました。手本の反転は2回です。
肩の軌道RMSEは0.1989radから0.2335radとなりました。
[比較結果](results/CYLINDER3_SWING_RESULTS.md)と同フォルダのJSONに根拠を保存しています。

この近似評価は後半開始時の正解姿勢から、時定数1秒の一次遅れ制御器で予測を戻すものです。
動画では把持・移動・解放を部分的に実現しましたが、机面より高い解放と復路の戻り不足が残りました。

## 再学習時の差分

公開用の学習コードでは、過去の大きな比較用モデルがなくても学習できるようbaseline_modelを任意としました。
最終設定はbaseline_model: nullです。既存bestを守るため、再学習先は
`~/checkpoints/train/ur5e_move_cylinder3_swing_v2_retrain`です。
同梱モデルを使う場合はREADMEの配置手順で重みとメタデータを導入します。

## 推論の受信対策

関節角・Gazebo時刻・保持状態は専用スレッドで受信します。
0.5秒超の遅延では新規指令を出さず待機し、3秒未満で受信が安定すれば古い予測を捨てて再予測します。
3秒以上の途切れ、時刻リセット、受信異常、大きな姿勢変化では停止を維持します。
待機中も送信済みの軌道は継続します。診断は `~/pai_training/ur5e_runs/` へ保存します。
