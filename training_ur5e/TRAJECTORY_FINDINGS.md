# 軌道の確認結果

学習済み`ur5e_move_cylinder_act`を、変換済みのep0・ep10・ep20から各32点、計96点で比較しました。
モデルの入力は保存された関節角、正解は同じ時刻の操作指令です。
再学習、Gazeboでの自動操作は行っていません。

| 関節 | AI予測と手本のRMSE | 現在角をそのまま出す場合のRMSE |
|---|---:|---:|
| shoulder_lift_joint | 0.0817rad（約4.7度） | 0.0642rad |
| elbow_joint | 0.0988rad（約5.7度） | 0.0811rad |
| wrist_3_joint | 0.0972rad（約5.6度） | 0.0673rad |

アームの最大絶対誤差は0.4646rad（約26.6度）でした。
これら3軸では、このサンプルに限ると「現在角をそのまま維持する」比較より誤差が大きくなっています。
対象は学習データなので、未知のデータに対する評価やタスク成功率ではありません。
実際の手先の軌道誤差、ずれが広がる時刻、繰り返し動作の成功率は未確認です。

一方、推論コードにはテレオペと異なり、アームの各指令に終端速度ゼロを付ける差がありました。
これを位置だけの指令に変更し、手本とそろえました。修正後の自動操作は未検証です。
把持待機、指の開閉の離散化も推論側の補助であり、手本と完全に同じ動作にはなりません。
学習済みモデルの重みと学習データは変更していません。

追加した`analyze.py`で同じ比較を実行できます。

```bash
cd ~/pai_training
pixi run python ur5e/analyze.py \
  --model-path /home/ubuntu/checkpoints/train/ur5e_move_cylinder_act
```

今後は、成功例だけのデータになっているか、開始・終了の待ち時間やリセット操作が混じっていないか、
同じ関節姿勢で異なる次動作を教えていないかを確認してから、学習の変更を判断します。
単純に学習回数を増やせば改善するとは、この結果だけでは言えません。
